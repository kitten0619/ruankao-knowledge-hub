模块1：统计学哲学基础 精炼版

模块1：统计学哲学基础

📋 核心要点速览

现代数据分析有三大范式：频率学派（实证主义，长期频率，p值/置信区间）、贝叶斯学派（确证理论，主观信念度，后验分布/贝叶斯因子）、数据科学/ML（溯因推理+实用主义，预测优先）。三者根植于不同哲学传统，核心分歧不在"概率是什么"而在优化目标（平均情况 vs 最坏情况）。实践中推荐混合策略：贝叶斯建模 + 频率学派验证。

🎯 关键概念卡片

三大范式对比

维度 频率学派 贝叶斯学派 数据科学/ML
哲学根基 实证主义+实在论 确证理论 溯因推理+IBE
概率诠释 长期重复频率 主观信念度 优化工具
参数观 固定未知常数 随机变量(有分布) 视算法而定
核心输出 p值、置信区间 后验分布、BF 预测值、特征重要性
推理逻辑 归纳+演绎 归纳(贝叶斯更新) 溯因→IBE

p值

定义：在H₀为真时，获得当前或更极端结果的概率
易错点：p值 ≠ H₀为真的概率 ≠ 效应大小。p=0.03不意味着H₀为真的概率是3%
要点：
- 20次独立检验(α=0.05)，至少1个假阳性概率≈64%
- 过度依赖p值是复制危机的重要原因

贝叶斯因子(BF)

公式：K = P(data|H₁) / P(data|H₀)
要点：
- 可支持零假设（p值做不到）
- 量化证据强度，非二元决策

Breiman的"两种文化"

  • 数据建模文化：关注真实数据生成模型（线性回归等）
  • 算法建模文化：只关心预测准确性（随机森林、SVM等）

📊 核心对比表：平均情况 vs 最坏情况

维度 贝叶斯 频率学派
核心目标 优化平均情况性能 优化最坏情况性能
比喻 精明投资者 谨慎工程师
关键输入 先验分布 p(θ) 数据生成假设
决策依据 后验期望效用最大化 最坏情况损失最小化

🔑 重点公式

  • MLE（频率学派）：θ̂_MLE = argmax P(data|θ)
  • 贝叶斯定理：π(θ|data) ∝ P(data|θ) · π(θ)
  • 经验风险最小化（ML）：f̂ = argmin (1/n)ΣL(yᵢ, f(xᵢ))

模块2：统计学核心概念 精炼版

模块2：统计学核心概念

📋 核心要点速览

统计学核心四大支柱：描述统计（集中趋势+离散程度+分布形态）、概率论（三大公理+贝叶斯定理+常见分布）、推断统计（CLT→置信区间→假设检验）、实验设计（随机化+控制+重复）。关键认知：p值≠效应量，统计显著≠实际重要，必须同时报告效应量。

🎯 关键概念卡片

集中趋势与离散程度

指标 特点 适用
均值 对异常值敏感 对称分布
中位数 对异常值稳健 偏态分布(收入/房价)
标准差 与原始数据同单位 最常用离散度量
IQR 抗异常值，反映中间50% 偏态数据

为何用n-1：样本方差用n-1得到总体方差的无偏估计

中心极限定理(CLT)

核心：n≥30时，样本均值近似正态分布，无论总体分布
- 形状：近似正态 | 中心：μ_x̄ = μ | 尺度：SE = σ/√n
- n增加4倍 → SE减半

置信区间 vs 可信区间

类型 频率学派(置信区间) 贝叶斯(可信区间)
解释 参数固定，区间随机 参数随机，区间固定
表述 "方法长期95%覆盖参数" "参数95%概率在此区间"

假设检验核心

  • p值 = P(数据|H₀为真)，不是 P(H₀为真|数据)
  • 两类错误：Type I (α, 错误拒绝) / Type II (β, 错误保留)
  • Power = 1-β：正确拒绝H₀的概率，受样本量、效应量、α影响

效应量必备

效应量 小/中/大 适用
Cohen's d 0.2/0.5/0.8 两组均值比较
η²/ω² 0.01/0.06/0.14 ANOVA
Cramer's V 0.10/0.30/0.50 卡方检验

🔑 重点公式

  • Z分数：z = (x - μ) / σ
  • 标准误：SE = σ / √n
  • CLT置信区间：x̄ ± z_{α/2} × σ/√n
  • 贝叶斯定理：P(A|B) = P(B|A)·P(A) / P(B)
  • 医学检测实例：患病率0.1%，灵敏度99%，特异度95% → P(患病|阳性) ≈ 1.9%

模块3：经典统计方法 精炼版

模块3：经典统计方法

📋 核心要点速览

六大经典方法：t检验家族（单样本/独立/配对）比较均值差异、ANOVA（单因素/双因素/重复测量）比较多组均值、线性回归建立连续变量关系、逻辑回归处理二分类、卡方检验分析分类变量关联、分类器评估衡量预测性能。核心逻辑：选方法看数据类型（连续/分类）和组数（1/2/3+）。

🎯 关键概念卡片

t检验家族

类型 场景 H₀ 额外假设
单样本 样本vs已知均值 μ = μ₀ 正态性
独立样本 两组均值比较 μ₁ = μ₂ 正态+方差齐(Levene)
配对样本 前后测/匹配 μ_D = 0 差值正态
方差不齐 → Welch t检验 违反正态 → 非参数替代(Mann-Whitney U / Wilcoxon)

ANOVA

  • F = MS_between / MS_within：组间变异 vs 组内变异
  • 双因素：可考察主效应 + 交互效应(A×B)
  • 球形假设（重复测量）：违反用Greenhouse-Geisser校正
  • 事后检验：Tukey(方差齐) / Games-Howell(方差不齐) / Bonferroni(最保守)
  • 效应量：偏η² = SS_between / (SS_between + SS_within)

线性回归

  • 模型：Y = β₀ + β₁X + ε，OLS最小化RSS
  • R² = 1 - RSS/TSS（决定系数），调整R²惩罚多余变量
  • 诊断问题：非线性/异方差/共线性(VIF>10)/异常值(Cook's D)
  • 变量选择：最优子集 / 逐步法 / AIC-BIC

逻辑回归

  • 模型：P(Y=1) = 1/(1+e^{-(β₀+β₁X)})，用MLE估计
  • OR = e^β₁：OR=1无关联，OR>1正向，OR<1负向
  • 评估：混淆矩阵→准确率/精确率/召回率/F1

分类器评估

指标 公式 侧重
精确率 TP/(TP+FP) 预测为正中多少对的
召回率 TP/(TP+FN) 实际为正中检出多少
F1 2PR/(P+R) 不平衡数据
ROC-AUC 曲线下方积 整体分类能力

🔑 重点公式

  • t统计量：t = (x̄ - μ₀) / (s/√n)
  • F统计量：F = MS_B / MS_W
  • R²：1 - RSS/TSS
  • χ²：Σ(O-E)²/E，期望频数<5用Fisher精确检验

模块4：贝叶斯统计 精炼版

模块4：贝叶斯统计

📋 核心要点速览

贝叶斯统计的核心是信念更新：先验 + 数据 → 后验。关键要素：先验选择（无信息/弱信息/有信息+共轭先验）、后验推断（点估计+可信区间+预测）、贝叶斯因子（假设检验+模型比较）、MCMC计算（当后验无解析解时）。应用涵盖贝叶斯t检验、ANOVA、回归、逻辑回归。

🎯 关键概念卡片

贝叶斯定理

公式：P(θ|D) = P(D|θ)·P(θ) / P(D) → 后验 ∝ 似然 × 先验
要点：
- 后验 → 新先验 → 持续更新（递推性）
- 大样本时先验被"冲销"，后验收敛于频率学派估计

先验分布三类型

类型 代表 特点
无信息 均匀/Jeffreys 最少假设，客观
弱信息 高方差正态/JZS柯西 正则化，防极端估计
有信息 共轭先验/经验贝叶斯 融入领域知识

三大共轭先验组合

组合 数据 后验更新
Beta-Binomial 二项(硬币/转化率) α+s, β+n-s
Gamma-Poisson 计数(来电/事件率) α+Σx, β+n
Normal-Normal 正态(方差已知) 精度加权平均

贝叶斯因子(BF)

  • BF₁₀ > 1：数据支持H₁ | BF₁₀ < 1：数据支持H₀
  • Jeffreys标度：1-3微弱, 3-10实质性, 10-30强, >30极强
  • 优势：可支持H₀（p值做不到）

MCMC方法

  • 问题：复杂模型的后验无解析解，需数值近似
  • Metropolis-Hastings：提议分布→接受/拒绝→马尔可夫链收敛于后验
  • Gibbs采样：MH特例，逐参数条件采样
  • 诊断：轨迹图(混合良好)、自相关图(低相关)、R̂≈1

📊 贝叶斯 vs 频率学派方法对比

方法 频率学派 贝叶斯
t检验 p值、置信区间 后验分布、BF、可信区间
ANOVA F统计量、η² 后验效应量、BF
回归 OLS、R²、p值 后验系数分布、可信区间
模型比较 AIC/BIC BF（直接比较边际似然）

🔑 重点公式

  • 贝叶斯定理：π(θ|D) ∝ L(θ|D)·π(θ)
  • Beta-Binomial后验：Beta(α+s, β+n-s)
  • BF：BF₁₀ = P(D|H₁) / P(D|H₀)
  • 可信区间：直接说"参数95%概率在此区间"

模块5：统计学习 精炼版

模块5：统计学习

📋 核心要点速览

统计学习 = 用数据估计f(X)来预测Y。核心框架：偏差-方差权衡（模型复杂度↑→偏差↓方差↑）。方法谱系：线性回归→正则化(Ridge/Lasso)→树方法(Bagging/RF/Boosting)→SVM→PCA→深度学习。评估工具：交叉验证(选模型)、Bootstrap(估不确定性)。核心原则：测试误差才是真性能。

🎯 关键概念卡片

偏差-方差权衡

公式：Err(x₀) = Bias² + Variance + σ²(不可约)
- 偏差↑：欠拟合（模型太简单）
- 方差↑：过拟合（模型太灵活）
- 最优模型在两者之和最小处

交叉验证

方法 偏差 方差 计算
验证集 中 高(依赖划分) O(1)
LOOCV 极低 高 O(n)
k-fold(k=5/10) 稍高 低 O(k) ← 推荐

正则化方法

方法 惩罚 特点
Ridge(L2) λΣβⱼ² 收缩系数，不置零
Lasso(L1) λΣ βⱼ
Elastic Net α·L1 + (1-α)·L2 兼顾两者

树方法

方法 核心思想 优缺点
Bagging 自助聚合，降低方差 好但不可解释
Random Forest Bagging+随机选特征 更robust
Boosting 序贯拟合残差，降偏差 强但需调参

SVM

  • 最大间隔分类器：找最大分隔超平面
  • 核技巧：高维映射解决非线性（RBF核最常用）
  • 关键参数：C(正则化)、γ(核宽度)

PCA

  • 正交变换→主成分(方差最大方向)
  • 用途：降维、去相关、可视化
  • 注意：需标准化，丢失可解释性

🔑 重点公式

  • 测试MSE分解：Bias² + Variance + σ²
  • Ridge目标：min RSS + λΣβⱼ²
  • Lasso目标：min RSS + λΣ|βⱼ|
  • k-fold CV：CV = (1/k)ΣMSEᵢ

模块6：数据可视化 精炼版

模块6：数据可视化

📋 核心要点速览

数据可视化 ≠ 画图，是数据驱动的探索与展示。核心原则：Tufte的数据墨水比最大化、图表垃圾最小化。图表选择取决于数据类型（分类/连续）和分析目标（分布/关系/比较/组成）。关键技能：EDA+残差诊断、多维可视化(散点图矩阵/平行坐标)、静态vs动态可视化的场景选择。

🎯 关键概念卡片

Tufte核心原则

  • 数据墨水比 = 用于数据的墨水/总墨水量 → 最大化
  • 图表垃圾最小化：去3D效果、阴影、装饰
  • 诚实性：不截断坐标轴、不用面积表一维数据

图表选择指南

目的 推荐图表
分布 直方图、箱线图、小提琴图、密度图
比较 条形图、箱线图、点图
关系 散点图、气泡图、热力图
组成 堆叠面积图、饼图(≤5类)、树图
趋势 折线图、面积图

Anscombe四重奏

四组数据统计摘要完全相同(均值/方差/r/回归线)，但散点图形态完全不同
→ 结论：相同统计量可掩盖截然不同的数据故事

多维可视化技术

方法 原理 限制
散点图矩阵 所有变量两两散点 变量多时拥挤
平行坐标 每变量一条垂直轴 交叉线多时难读
颜色/大小/形状编码 在2D图上叠加维度 维度≤4有效

残差诊断图

  • 残差vs拟合值：检查线性+方差齐性(应无模式)
  • Q-Q图：检查正态性(点贴近对角线)
  • Scale-Location图：检查方差齐性
  • 残差vs杠杆：识别强影响点(Cook's D)

传统假设检验的核心局限

LDA(线性判别分析)

第2章：经典伦理理论体系（1.4-1.9）

2.1 幸福主义伦理学 (Eudaimonism)

核心理论基础

  • 理论根源：古希腊哲学传统（苏格拉底、柏拉图、亚里士多德、伊壁鸠鲁、斯多葛派）
  • Eudaimonia 定义：不同于短暂快乐，指通过始终践行美德而实现的客观、持久的人类繁荣
  • 美德导向：勇气、智慧、正义、节制等美德是美好生活本身的内在组成部分，而非手段

核心操作逻辑

  • 品格聚焦：基于个体品格在整个生命周期中的全面发展来评估道德表现
  • 社会属性：真正的幸福只有在社会环境中才能实现
  • 情境判断：优先考虑细微判断和实践智慧，而非严格遵守规则

与其他伦理体系的差异

特征 幸福主义 功利主义 义务论
评判标准 品格发展 行为结果 规则遵循
关注焦点 成为什么样的人 做什么 遵守什么
典型问题 "这是否促进人的繁荣？" "这是否带来最大幸福？" "这是否违背普遍规则？"

AI领域应用

  • 数据科学家将透明度置于效率之上
  • 招聘AI设计师融入同理心确保公平
  • 评估举报人（如Frances Haugen）时关注道德勇气和正直，而非结果

2.2 义务论伦理学 (Deontology)

核心理论基础

  • 创始人：康德（Immanuel Kant），启蒙运动时期
  • 核心原则：道德价值完全取决于行为是否出于义务，与结果无关
  • 定言命令（Categorical Imperative）：核心规则（不撒谎、不偷窃）是绝对的

康德的三个公式

  1. 普遍性公式：只按你愿意成为普遍法则的准则行动
  2. 人性公式：永远把人当作目的，而非手段
  3. 自律公式：每个理性存在者都是道德法则的立法者

应用案例

场景 义务论判断 理由
隐瞒病情 ❌ 错误 侵犯患者知情权
提高差生成绩 ❌ 不道德 违背公平评估的核心职责
酷刑逼供 ❌ 绝对不可接受 侵犯人的固有尊严

核心批评

  • 绝对规则的刚性：为救犹太难民而对纳粹撒谎被广泛认为道德合理，挑战了绝对禁止违反规则的立场

2.3 功利主义伦理学 (Utilitarianism)

理论演变

  • 思想渊源：古希腊伊壁鸠鲁学派
  • 边沁（Bentham）：现代功利主义创始人，提出享乐微积分
  • 密尔（Mill）：区分高级智力快乐与低级肉体快乐

核心框架

  • 结果主义：仅根据行为的实际结果判断道德有效性
  • 两大分支：
分支 核心逻辑 优势 缺陷
行为功利主义 每个行为单独评估其直接后果 灵活 可能导致不公正
规则功利主义 遵循能产生最大长期利益的普遍规则 稳定性 可能过于僵化

主要批评

  • 少数群体剥削漏洞：可能被威权政权利用为审查辩护
  • 人权冲突：集体利益可能损害边缘化群体

2.4 新亚里士多德主义 (Neo-Aristotelianism)

核心框架

  • 美德中心论：道德评价聚焦于行为者的品格特质
  • 实践智慧（Phronesis）：在具体情境中运用实践智慧做出正确判断
  • 中庸之道（Golden Mean）：美德是两个极端之间的适中点
  • 勇敢 = 懦弱 ← 勇敢 → 鲁莽
  • 节制 = 麻木 ← 节制 → 放纵

独特优势

  • 避免功利主义单一原则计算的过度简化
  • 避免康德义务论固定法则的僵化
  • 提供全面、以人为本、因地制宜的框架

2.5 平等主义伦理学 (Egalitarianism)

核心原则

  • 理论渊源：卢梭（Rousseau）的社会平等与集体意志
  • 三大支柱：平等、公平、正义
  • 核心信条：所有个体具有平等的道德价值，社会差异必须得到合理证明

罗尔斯的正义理论

  • 无知之幕（Veil of Ignorance）：规则制定者在不知道自身社会身份的情况下设定制度
  • 分蛋糕隐喻：公平的决策需要摆脱个人私利偏见
  • 务实取向：支持适度不平等而非绝对平均化，确保所有人获得发展所需的"基本善"

支持的政策类型

  • 累进税制
  • 全民医疗保健
  • 平权行动（Affirmative Action）
  • 普遍基本收入（UBI）

2.6 境遇伦理学 (Situation Ethics)

核心原则

  • 不是道德主观主义：保留"充满爱心行事"的固定目标，但拒绝一刀切规则
  • Agape（圣爱）：无条件的、以他人为中心的爱是最高道德原则
  • 情境至上：道德判断必须考虑具体情境，没有放之四海而皆准的规则

应用案例

场景 境遇伦理学判断
安乐死 ✅ 支持（减轻不可忍受的痛苦符合圣爱）
为救人而说谎 ✅ 道德义务（保护弱势群体）
公民抗命 ✅ 道德责任（追求集体正义）

核心批评

  • 可扩展性障碍：抽象的"爱"原则没有明确操作指标
  • 意外后果风险：大规模人道主义政策可能引发资源短缺等问题

3.1 前AI时代计算伦理

各时代核心伦理问题

4.1 两种数据类型的本质对比

第6章：隐私、保密与安全的博弈（2.3）

6.1 核心概念辨析

概念 定义 关注焦点 典型示例
🔒 隐私 (Privacy) 个人控制对其个人信息访问的权利 个人对自身信息的权利和自主权 决定谁可查看健康记录
🤫 保密 (Confidentiality) 受委托方保护信息免于未授权访问的义务 信任关系内共享信息的保护责任 医生对患者病历保密
🛡️ 安全 (Security) 防御网络威胁、保护数据免于泄露的技术措施 系统层面的防御与应对 网络安全工具、事件响应

6.2 隐私与安全的根本矛盾

"我们既希望免受监控，又希望获得监控带来的保护——但这两个目标可能相互矛盾。"

我们想要的... 矛盾之处
隐私不被侵犯 但被黑客攻击时希望有广泛日志来追踪罪犯
不被网络追踪 但设备丢失时希望科技公司能定位追踪
数据不被监控 但遭受数据泄露后要求更强的监控能力

欧洲：GDPR全球基准

第9章：被遗忘权与法律监管（2.7）

9.1 被遗忘权 (Right to Be Forgotten, RTBF)

核心概念

  • 定义：个人有权要求删除不再相关或对其生活产生负面影响的过去记录
  • 起源：2014年欧洲法院 (ECJ) 确立
  • GDPR条款：当数据对收集目的不再重要、个人撤回同意、或数据被非法处理时，可要求删除
  • 核心矛盾：个人隐私权 vs 历史事实保存 + 公众知情权

全球法律对比

地区 被遗忘权状况
🇪🇺 欧洲 最发达——GDPR赋予明确权利，ECJ 2014年确立
🇺🇸 美国 无全面RTBF法律；加州CCPA赋予部分删除权
🇯🇵 日本 2017年最高法院判决：权衡公众知情权 vs 隐私权，倾向于前者

9.2 被遗忘权经典案例

案例 时间 判决结果 核心逻辑
Costeja González 诉 Google 2014 ✅ 原告胜诉 搜索引擎须删除"不充分、不相关或不再相关"的信息
荷兰外科师案 2019 ❌ 原告败诉（上级法院推翻） 试图删除停职记录——公共利益 > 个人隐私

NT2 诉 Google 2018 ✅ 请求支持 窃听罪（刑期短）——已不相关，隐私权优先

⚠️ 残酷现实：几乎没有什么内容会被真正删除和遗忘。

  • 网站存档工具（如 Wayback Machine 自1996年起收集快照）
  • 时间旅行工具（timetravel.mementoweb.org）
  • 信息一旦上网，可能永久存在

9.5 法律与监管挑战

挑战维度 具体表现

"尽管技术进步有缺点，我们并不主张逆转工业化、禁止车辆或拆除互联网。社会的目标是在进步与降低风险之间取得平衡。同样的道理也适用于大数据和人工智能。"

1.1 为什么需要文本挖掘？

结构化数据的局限性

局限 说明 例证
预设框架约束 将复杂现实映射到预设理论框架，遗漏创造力、情商等核心维度 IQ测试简化人的智力

文本挖掘的核心优势

  1. 互补性根本原因识别：数值数据只反映"是什么"，文本挖掘揭示"为什么"
  2. 实时响应支持：对社交媒体、新闻源的实时文本挖掘可即时洞察公众情绪
  3. 偏差减少效应：全面分析完整非结构化数据集，发现传统框架忽略的联系
  4. 混合方法赋能：结合定性研究深度与大规模定量分析严谨性

第5章：文本预处理（Text Preprocessing）

来源：Week 2 章节补充学习内容
核心主题：将原始文本转换为算法可处理的结构化格式

5.1 文本预处理概述

定义

文本预处理（Text Preprocessing）是为机器学习模型或自然语言处理（NLP）任务准备原始文本时的关键步骤。其目标是将文本转换为算法易于理解的结构化格式。

预处理流程全景

原始文本 → 分词(Tokenization) → 小写转换 → 停用词移除 → 词干提取/词形还原 → 特殊字符处理 → 数值化处理(TF-IDF/词嵌入)

核心步骤组成

步骤 英文术语 目的
分词 Tokenization 将连续文本拆分为独立的标记（token）
词干提取 Stemming 通过去除后缀将单词还原为词干形式
词形还原 Lemmatization 运用语言学知识将单词转换为词典基础形式
停用词移除 Stop-word Removal 删除对分析无贡献的高频功能词
特殊字符处理 Special Character Handling 移除或保留标点、符号等非文字字符
小写转换 Lower Casing 统一大小写，避免同一词被识别为不同标记

5.2 分词（Tokenization）

核心定义

分词是将文本分割成更小单位（词、短语、符号等）的过程，这些单位称为标记（Token）。

分词的注意事项

  • 标点符号需要与单词分开处理，但结果必须保持意义
  • 例：IP地址"129.2.13.105"中的句点不能简单删除，否则变成无意义的"129213105"
  • 分词粒度可以是词级别、子词级别或字符级别

5.3 词干提取（Stemming）

定义

词干提取通过去除诸如"ing""ed""ly"之类的后缀，将单词还原为其词干形式。它借助启发式方法实现，所得结果不一定都是有效的单词。

示例

原始词：["fishing", "fished", "fisher"]
提取词干后：["fish", "fish", "fisher"]

"fishing"和"fished"都被简化为"fish"，而"fisher"保持不变。

三大词干提取器对比

维度 Porter 词干提取器 Snowball 词干提取器 Lancaster 词干提取器
别名 Porter Stemmer Porter2 Stemmer Lancaster Stemmer
开发者 Martin Porter (1980) 基于Snowball语言开发 Lancaster大学
核心原理 去除英语常见形态和屈折词尾 基于Porter改进，更先进 使用外部规则进行迭代运算
激进程度 适中 比Porter更激进 最激进
多语言支持 ❌ 仅英语 ✅ 支持多语言 ❌ 主要英语
速度 快 比Porter更快 较快，但处理短单词可能混淆
准确率 速度与准确率的较好平衡 综合表现最佳 可能过度提取（over-stemming）
适用场景 文本挖掘、信息检索 多语言文本处理 对速度要求极高的场景

🔑 选择建议：对于英语文本，Porter通常在速度和准确率之间实现了较好的平衡；Snowball（Porter2）是更先进、更广泛使用的选择；Lancaster最激进，需注意短单词处理问题。

Python代码示例（NLTK词干提取）

from nltk.stem import PorterStemmer, SnowballStemmer, LancasterStemmer

# 初始化三种词干提取器
porter = PorterStemmer()
snowball = SnowballStemmer("english")
lancaster = LancasterStemmer()

words = ["running", "ran", "runner", "fishing", "fished", "better"]

# 对比三种提取器
for word in words:
    print(f"{word:12s} → Porter: {porter.stem(word):10s} | "
          f"Snowball: {snowball.stem(word):10s} | "
          f"Lancaster: {lancaster.stem(word)}")

5.4 词形还原（Lemmatization）

定义

词形还原与词干提取类似，但它运用语言学知识将单词转换为其基础形式或词典形式（词元，Lemma）。与词干提取不同的是，词形还原的结果是真实存在的单词。

示例

词形还原：["running", "ran", "runner"] → ["run", "run", "runner"]

词干提取 vs 词形还原对比

维度 词干提取（Stemming） 词形还原（Lemmatization）
方法 启发式规则（去后缀） 语言学知识（词汇+形态分析）
结果 不一定是有效单词 一定是词典中的有效单词
速度 快 较慢
典型工具 NLTK PorterStemmer NLTK WordNetLemmatizer

第6章：停用词移除（Stop-word Removal）

核心主题：移除对分析无贡献的高频功能词，保留有信息量的内容词

6.1 定义与原理

核心定义

停用词（Stop Words）是在文本分析中被过滤掉的常见词，如"a""an""the""is""am""are""however""although""but"等。这些词在语言中频率很高，但对区分文档主题或内容几乎没有贡献。

移除停用词的意义

  • 减少数据维度：降低特征空间大小
  • 提升计算效率：减少不必要的处理量
  • 提高分析质量：让模型更关注有信息量的词汇

6.2 停用词的争议

⚠️ 重要提醒：停用词移除并非总是正确的选择。在某些情况下，停用词可能包含重要信息：
- "To be or not to be"（"生存还是毁灭"）—— 莎士比亚名句的核心含义恰好在停用词中
- "但是"可以完全颠覆句子的概念："房间很漂亮，但颜色不是我喜欢的"
- BERT等现代模型已经能够利用上下文中的停用词信息进行理解

第7章：词频-逆文档频率（TF-IDF）

核心主题：将文本转化为数值特征的核心统计方法

7.1 TF-IDF定义

TF-IDF（Term Frequency-Inverse Document Frequency，词频-逆文档频率）是文本挖掘和信息检索中用于评估一个词对文档集合中某篇文档重要性的统计度量。

  • 某词在文档中的重要性与其在该文档中的出现频率成正比
  • 同时与该词在整个文档集合中的出现频率成反比

核心应用场景

  • 关键词提取
  • 文档相似度计算
  • 文本分类的特征工程
  • 搜索引擎排序

7.2 公式详解

总公式

TF-IDF(t, d) = TF(t, d) × IDF(t, D)

其中：
- t = 术语（Term），即某个词
- d = 特定文档（Document）
- D = 整个文档集合/语料库（Corpus）

词频 TF（Term Frequency）

衡量某词 t 在文档 d 中的出现频率：

TF(t, d) = 词 t 在文档 d 中的出现次数 / 文档 d 的总词数

计算示例：

文档内容："I ate an apple, which was a very delicious and satisfying snack for my busy day. What a great luxury."
- "apple"的出现次数 = 1
- 文档总词数 = 20
- TF("apple") = 1/20 = 0.05

逆文档频率 IDF（Inverse Document Frequency）

衡量某词 t 在语料库所有文档中的罕见程度：

IDF(t, D) = log(文档集合 D 的总文档数 / 包含词 t 的文档数)
  • 若词出现在所有文档中：分母 = 分子，log(1) = 0，IDF 值为 0
  • 若词出现在较少文档中：分母更小，IDF 值更高 → 该词更具信息量

计算示例：

语料库有 10,000,000 篇文档，"apple"出现在 1,000 篇中
IDF("apple") = log(10,000,000 / 1,000) = log(10,000) = 4

TF-IDF得分计算

TF-IDF("apple") = TF × IDF = 0.05 × 4 = 0.2

第8章：N元语法（N-gram）

核心主题：捕捉词语序列关系的文本表示方法

8.1 定义

N-gram 是从文本中提取的连续 n 个词（或字符）的序列。它保留了词序信息，弥补了词袋模型（Bag of Words）丢失词序的缺陷。

8.2 N-gram类型

类型 N值 示例（文本："I love text mining"）
Unigram 1 ["I"], ["love"], ["text"], ["mining"]
Bigram 2 ["I love"], ["love text"], ["text mining"]
Trigram 3 ["I love text"], ["love text mining"]

8.3 应用场景

  • 语言建模：预测下一个词的出现概率
  • 拼写检查：基于N-gram频率判断合理搭配
  • 信息检索：短语搜索比单词搜索更精确
  • 文本分类：Bigram/Trigram可捕捉更有意义的特征组合
  • 机器翻译：评估翻译结果的自然度

💡 选择建议：N值越大，捕捉的上下文信息越丰富，但数据稀疏性也越高。实际应用中 Bigram（N=2） 和 Trigram（N=3） 最为常用。

第9章：词嵌入（Word Embedding）

核心主题：用密集向量表示词语语义关系的分布式表示方法

9.1 词嵌入概述

核心定义

词嵌入（Word Embedding）是一类将单词映射到密集、低维度向量的技术。与TF-IDF的稀疏高维表示不同，词嵌入能够捕捉语义关系——语义相似的词在向量空间中距离更近。

与TF-IDF的区别

维度 TF-IDF 词嵌入（Word Embedding）
表示方式 稀疏高维向量 密集低维向量
语义信息 仅反映词频统计 捕捉语义相似性
维度 等于词汇表大小 通常100-300维
上下文 不考虑词序和语境 通过训练捕捉语境关系

9.2 Word2Vec

核心思想

Word2Vec 由 Google 于 2013 年提出，通过浅层神经网络学习词的分布式表示。有两种训练架构：

架构 原理 适用场景
CBOW（连续词袋） 根据上下文词预测目标词 较小数据集、较快训练
Skip-gram（跳字模型） 根据目标词预测上下文词 较大数据集、稀有词表现更好
